Recipe Box 🍽️
A full-stack recipe management application built with Node.js, Express, MongoDB, and deployed on Vercel.

Live Demo
Live Application: https://recipebox-jhyj.vercel.app

Features
User Authentication - Secure login with OTP verification

Recipe Management - Create, read, update, and delete recipes

Admin Dashboard - User management and system monitoring

Email Notifications - OTP sending via Nodemailer

Security - Helmet, CORS, rate limiting, and data sanitization

Responsive Design - Works on desktop and mobile devices

Tech Stack
Backend
Node.js - Runtime environment

Express.js - Web framework

MongoDB - Database with Mongoose ODM

MongoDB Atlas - Cloud database service

Security
Helmet.js - Security headers

CORS - Cross-origin resource sharing

express-rate-limit - Rate limiting

express-mongo-sanitize - NoSQL injection protection

xss-clean - XSS protection

hpp - HTTP parameter pollution protection

Authentication & Sessions
express-session - Session management

connect-mongo - Session storage in MongoDB

cookie-parser - Cookie handling

Email Service
Nodemailer - OTP email delivery

Gmail SMTP - Email transport

Deployment
Vercel - Serverless deployment platform

Environment Variables - Secure configuration management
